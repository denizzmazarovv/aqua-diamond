# AQUADIAMOND — сайт

Одностраничный сайт ООО «AQUADIAMOND» (Ташкент) — производителя газированного напитка Moxito в банке.

- Три языка: русский, o'zbekcha, English
- Каталог вкусов, информация для партнёров, где купить
- Калькулятор оптовой заявки

Сайт — один файл `index.html`, без сборки. Чтобы отправить изменения на GitHub, запустите `push.bat`. Публикация через GitHub Pages: Settings → Pages → Deploy from branch → `main`.

## Перед запуском заполнить
- Телефон, адрес и часы работы (раздел «Контакты»)
- Подключить отправку заявок в Telegram
- Заменить нарисованные банки фотографиями продукции
