# Исходники сайта AQUADIAMOND

Здесь лежат исходники, из которых собирается сайт (файлы в корне репозитория — это результат сборки).
Папка начинается с «_», поэтому GitHub Pages её не публикует.

- `page.html` — главная страница (одна для всех языков, тексты UZ/EN в словаре `T` внутри скрипта; настройки — блок `CONFIG`).
- `build_seo.py` — собирает сайт в папку `site/`: RU `/`, `/uz/`, `/en/`, политика, robots, sitemap, llms.txt, analytics.js, Schema.org.
- `privacy_content.py` — тексты политики конфиденциальности (RU/UZ/EN).
- `prerender.js` — переводит /uz/ и /en/ прямо в HTML и добавляет FAQ-разметку (нужен Node + Playwright).
- `og.js`, `icons.js` — картинка-превью для соцсетей и проверки.
- `csp.py` — последний шаг сборки: ставит на каждую страницу Content-Security-Policy с SHA-256 встроенных скриптов (защита от XSS). Запускается после `prerender.js`; если вручную править HTML в корне, обязательно пересоберите сайт, иначе изменённый скрипт браузер заблокирует.
- Флаги для выбора кода страны в форме — `../img/flags/*.svg` (country-flag-icons, MIT). Список стран и маски номеров — массив `CC` в `page.html`.
- `build_all.sh` — полная сборка: `bash build_all.sh`, затем скопировать содержимое `site/` в корень репозитория.
- `render_cans.py` — как из PDF-макетов этикеток сделаны объёмные банки.
- Картинки товаров берутся из `../img/`, логотип — `brand-src/emblem-512.png` и `../img/brand/`.
- Скрипт Google Таблицы — `../apps-script/Code.gs`.
